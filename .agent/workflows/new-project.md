# New Project Initialization & Scaffolding

Workflow for initializing and verifying the AcademiaTrack digital class record application.

## Steps
1. Verify Node.js and npm versions.
2. Confirm React + TypeScript + Vite and Vanilla CSS setup.
3. Check and run database migrations in `src/supabase/schema.sql`.
4. Start development server using `npm run dev`.
