# Digital Class Record & Attendance Management System

A multi-role university web application (Admin / Instructor / Student) that digitizes class records, daily attendance via rapid roll-call, categorized grades with cross-module sync, and real-time academic standing.

## Stack

- **Next.js 15** (App Router) + TypeScript
- **Tailwind CSS 4** for styling
- **Supabase** for auth, database, storage, and realtime
- **Framer Motion** for animations

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
